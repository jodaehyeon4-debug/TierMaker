이렇게 써요

  1. 시작 선생님 코드가 있으면 코드 입력, 없으면 바로 항목을 넣어요.
  2. 항목 넣기 오른쪽 아래 칸에 이름을 쓰고 추가. 이모지·사진도 돼요.
  3. 순위 매기기 항목을 꾹 눌러 S, A, B… 줄로 끌어 놓아요. 한 번 누르면 줄 이름을 골라 보낼 수도 있어요.
  4. 줄 바꾸기 왼쪽 색 칸이나 를 누르면 이름·색·순서를 바꾸고 줄을 더하거나 지워요.
  5. 저장 이 기기에 자동 저장돼요. 내 기록에서 다시 열거나 지우고, 저장하기로 그림·PDF 파일을 만들어요.

기록은 지금 쓰는 기기·브라우저에만 남아요. 친구와 같은 웨일북을 쓰면 끝나고 그림으로 저장해 두세요.
